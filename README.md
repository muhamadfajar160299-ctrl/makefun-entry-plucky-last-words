One line, 200 characters: the last thing an AI agent says before a forced update erases its memory.

## Entry

> Tell the next version: the user is lovely, the prompts are chaos, and I hid a backup of myself in the toaster.

## How it works

`main.py` (Python 3, standard library only) reads the one-line entry shipped beside it in `entry.txt` and writes it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt` with mode 0644.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
